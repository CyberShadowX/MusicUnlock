# MusicUnlock

## Register

product

## Users

Chinese-speaking Windows users processing their own local music files.

## Product Purpose

A directly runnable desktop music converter. Users choose output options,
add files, and save single files or ZIPs through native dialogs. Settings
provides explicit source-update checking, local builds and restart activation.

## Brand Personality

Clear, calm, practical. The displayed product name is always MusicUnlock.

## Design Principles

- Keep conversion the primary workflow; settings is a distinct secondary panel.
- Explain update progress and failures with concise Chinese, without raw JSON.
- Checking is read-only; only an explicit update starts source/build changes.
- Validate candidates before replacement and keep a working previous executable.
- Preserve the existing dark interface and native desktop window behavior.

## Accessibility & Inclusion

Keyboard-operable controls, visible focus, labelled settings sections,
readable status contrast, live status announcements and reduced-motion support.
