The desktop renderer uses the installed Windows Microsoft WebView2 Runtime.
Microsoft WebView2 SDK interop/loader files are supplied with pywebview:
https://learn.microsoft.com/microsoft-edge/webview2/

FFmpeg is a separate executable invoked as a subprocess:
https://ffmpeg.org/ and https://www.gyan.dev/ffmpeg/builds/
This local build copies an already installed FFmpeg, without modifying it.
Its exact version, configuration identity and SHA256 are in build-info.json.
The installed build used here is GPL-3.0-or-later; its full license is included
inside the executable and beside it in licenses/FFmpeg-LICENSE.txt.
Corresponding FFmpeg source: https://git.ffmpeg.org/ffmpeg.git
The local version identifies commit 44a0148fad (2023-11-05).

Python and runtime package license files are collected inside the executable
under licenses/. Project and FFmpeg notices are also supplied beside it.
These notices do not change any dependency's license or upstream format support.
